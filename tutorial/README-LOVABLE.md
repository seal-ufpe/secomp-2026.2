# Tutorial: criando uma conta no Lovable

O Lovable transforma uma descrição em linguagem natural em um aplicativo web. Use este guia
para criar uma conta, iniciar um projeto e obter uma URL que possa ser compartilhada.

## 1. Criar a conta

1. Acesse [lovable.dev](https://lovable.dev/).
2. Selecione **Sign up** ou **Get started**.
3. Entre com sua conta Google ou GitHub, ou informe e-mail e senha.
4. Confirme os termos e conclua a verificação solicitada.

## 2. Criar o projeto

1. No painel, selecione **New project**.
2. Descreva o que deseja construir. Inclua as páginas, ações, cores e informações que o
   aplicativo deve ter.
3. Revise a primeira versão no preview.
4. Peça ajustes pelo chat e teste cada alteração antes de publicar.

## 3. Publicar

1. Clique em **Publish** no projeto.
2. Escolha um nome público para o projeto e confirme a publicação.
3. Abra o link gerado em uma janela anônima para conferir que ele está acessível.
4. Copie a URL publicada. Ela será usada no cadastro da SECOMP.

## 4. Postar na galeria da SECOMP

1. Acesse [secomp-2026-2.vercel.app](https://secomp-2026-2.vercel.app/).
2. Selecione **Novo projeto**.
3. Informe título, nome do autor, descrição e a URL pública do Lovable.
4. Escolha **Lovable** como origem e clique em **Publicar projeto**.

Não compartilhe senhas, tokens ou variáveis de ambiente no chat do Lovable ou na descrição do
projeto.
